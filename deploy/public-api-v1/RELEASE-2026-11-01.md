## Отклонение при выкладке

Первый запуск из другого cwd подставил `PWD=/root` в старый Compose и получил
пустые bind directories вместо прежних хранилищ; сервис не мог прочитать
config.yaml и уходил в restart. Публичный ключ был закрыт. Реальные stores в
`/opt/CliRelay` не заменялись. Overlay теперь закрепляет все четыре абсолютных
bind source и `create_host_path: false`; повторный запуск из `/opt/CliRelay`
восстановил сервис, old-Hermes и сравнение старых записей прошли. Это был
промежуток недоступности CliRelay, несмотря на отсутствие restart Hermes.
Автоматическая проверка отклонила необязательную очистку пустых каталогов от
этого запуска как не входящую в согласованный scope; они оставлены без изменений.

## Настроен целевой ноутбук

По запросу владельца выполнена настройка через существующий SSH-доступ.
Реально установлен bundled CLI `0.166.0-alpha.5.1`, macOS 15.7.7/arm64;
локальный mock подтвердил нормализацию query версии каталога до `0.166.0`.
Серверный runtime не менялся повторно для этого клиента.

Владелец отдельно отменил Keychain и попросил заменить ModelHub и ключ:
целевой `~/.codex/config.toml` теперь выбирает CliRelay/Gemini/medium и хранит
credential штатным `experimental_bearer_token` с правами 0600. Прежний конфиг
оставлен только на ноутбуке в закрытой копии 0700/0600. Состояние OpenAI auth
не менялось. Прежние context overrides 353k/300k удалены, используется каталог
Gemini. Никаких Xcode/других компонентов на ноутбук не устанавливалось.
Попытка запуска системного Python stub вызвала предложение установки Xcode;
далее использован уже имеющийся Node. Одноразовый Keychain helper не сохранял
credential и удалён после отмены Keychain владельцем.

На самом ноутбуке выполнен реальный HTTP/SSE test: shell read, apply_patch,
verification read, final answer и follow-up с recalled marker; обе команды
завершились exit 0, удалённый каталог содержит единственный Gemini slug.
Первая попытка дала неверный unified-diff header и пустое продолжение модели;
повтор с явным native bare-@@ форматом прошёл. Серверные adapters не менялись
для этого повтора. В тесте не загружались пользовательские чаты/MCP; временный
provider config удалён, дополнительная копия нового ключа в test artifacts
не обнаружена. 2026-11-01 владелец подтвердил после перезапуска ChatGPT:
Gemini появилась и отвечает в новом чате Codex. Это owner-проверка выбора
модели и текстового ответа в desktop UI; инструменты и follow-up проверены
отдельно целевым CLI.

Локальный CLI test, target-Mac CLI test, owner Telegram acceptance и
пользовательская проверка нового desktop-чата завершены.
Действующие Google-лимиты могут изменяться и являются
общими для аккаунта; отдельный внешний пул не резервирует upstream-квоту Hermes.
