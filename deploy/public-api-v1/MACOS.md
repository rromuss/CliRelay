# Подключение ноутбука

Серверный адрес: `https://cliprelay.romus.pro:8443/v1`.
Проверенные версии клиента — Codex CLI 0.166.0 и bundled
0.166.0-alpha.5.1 на целевом Mac. Последний передаёт `client_version=0.166.0`.
На сервер Codex не установлен:
клиент запускается на Mac, а HTTPS API обслуживает CliRelay.

## Текущий целевой Mac

По отдельному явному указанию владельца **Keychain не используется**: провайдер
ModelHub заменён на CliRelay, новый ключ находится только в клиентском
`~/.codex/config.toml` (0600). Прежний конфиг сохранён в закрытом backup-каталоге
только на этом Mac (0700/0600); в репозитории ключа нет. Использован штатный
`experimental_bearer_token`, как в прежней настройке ModelHub.

Выбраны `gemini-3.8-flash-tiered`, medium, HTTP/SSE, удалённый каталог;
web search и retries выключены. Два прежних ModelHub context overrides удалены,
чтобы Gemini использовал пределы своего каталога. Остальные настройки и
состояние авторизации OpenAI не менялись.

Установленный на этом Mac CLI выполнил read/patch/read и продолжение диалога
через публичный HTTPS. Изолированные тесты не загружали пользовательские чаты
или MCP; временные копии credential удалены. 2026-11-01 владелец подтвердил
после перезапуска ChatGPT: Gemini появилась и отвечает в новом чате Codex.
Инструменты проверены целевым CLI; выбор модели и текстовый ответ в desktop UI
подтверждены владельцем.

Для такой настройки есть `codex-macos-inline.toml.example` с фиктивным
placeholder. Настоящий ключ вводится только на клиенте; не вставляй его в
репозиторий, переписку или аргументы команд.

## Генерация изображений

Подключён локальный MCP-сервер `clirelay_images`, инструмент `imagegen`.
Основной моделью остаётся Gemini 3.8 Flash, а картинку создаёт отдельная
`gemini-3.1-flash-image` (Nano Banana 2) через существующий ключ CliRelay.

1. Перезапусти ChatGPT на ноутбуке и открой новый чат Codex с Gemini.
2. Напиши, например: **«Сгенерируй фотореалистичную клубнику в разрезе
   на белом фоне»**. Можно попросить горизонтальный или вертикальный формат.
3. Если появится запрос на использование `imagegen`, подтверди его.
4. Готовое изображение возвращается в ответе; файл сохраняется также в
   `~/Pictures/CliRelay` (каталог 0700, изображения 0600).

2026-11-01 владелец подтвердил появление готовой картинки в новом Gemini-чате
после обычного запроса о клубнике в разрезе.

Поддерживается генерация по текстовому описанию, одна картинка 1K за вызов,
пропорции 1:1, 16:9 и 9:16. Дополнительный OpenAI API key не нужен.
Если инструмент не появился после перезапуска, проверь `/mcp` и сервер
`clirelay_images`. Не подменяй генерацию SVG и не добавляй OpenAI-ключ ради
этой схемы. Разрешения остальных инструментов и shell не менялись.

Выпуск и проверки: `IMAGES.md`. Image MCP на текущем целевом Mac читает
выбранный владельцем inline credential из конфига 0600; альтернативный
Keychain-пример ниже относится к подключению основного текстового провайдера.

## Альтернативный вариант с Keychain

Следующие шаги оставлены для клиентов, где владелец выбирает Keychain.
На текущем целевом Mac они не применялись.

1. Через прежнюю SSH-панель CliRelay открой ключ **Codex — ноутбук**. Его
   отдельный профиль разрешает только выбранный новый Antigravity-аккаунт и
   `gemini-3.8-flash-tiered`: 10 запросов/минуту, 300 начатых запросов/сутки UTC,
   не больше двух одновременно. В чате, терминальных аргументах и TOML ключ
   не размещай. После копирования очисти clipboard.
2. На ноутбуке открой **Keychain Access / Связка ключей**, создай обычный
   password item в связке login: имя/service
   `CliRelay:cliprelay.romus.pro:8443`, account `codex-laptop`, password — этот
   API-ключ. Ввод и подтверждение выполняет владелец ноутбука.
3. В существующий `~/.codex/config.toml` аккуратно перенеси значения из
   `codex-macos.toml.example`. Не заменяй весь файл и не дублируй уже имеющиеся
   root-параметры. Сохрани остальные provider tables и OpenAI-авторизацию.
   Пример выбирает CliRelay провайдером по умолчанию для новых чатов.
4. Полностью перезапусти Codex, создай новый чат и выбери Gemini 3.8 Flash,
   medium. При первом запросе разреши доступ к созданному item в системном
   диалоге Keychain. Для обращений к модели SSH и VPN не нужны.
5. В отдельном тестовом каталоге попроси прочитать файл, выполнить безопасную
   команду, изменить файл через patch и задать следующий вопрос в том же чате.
   CLI-проверка уже выполнена на целевом Mac; acceptance именно desktop UI
   ею не подменяется.

Доступны текст, локальные инструменты и указанная генерация изображений.
Hosted web search, image edits/uploads, WebSocket и другие API-модели
не опубликованы. Лимит — начатые
модельные запросы, поэтому один диалог с несколькими tool rounds может занять
несколько запросов. Ошибка upstream после допуска также считается. Квота
Google-аккаунта остаётся общей с другими его потребителями.

Отзыв доступа: в закрытой панели выключи у этого ключа **External access**.
Отказ для следующих запросов действует сразу. Если меняешь само значение
ключа, обнови credential клиента: конфиг 0600 для текущего целевого Mac или
item Keychain для альтернативного варианта, затем перезапусти клиент. Лимиты
привязаны к ID ключа и не сбрасываются. Чтобы вернуть прежний провайдер по умолчанию, восстанови
только ранее выбранные root model/provider settings.

Командная авторизация и удалённый каталог — штатные механизмы Codex:
[официальная инструкция по gateway](https://learn.chatgpt.com/docs/enterprise/roll-out-a-gateway).
