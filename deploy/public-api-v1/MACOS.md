# Подключение ноутбука

Серверный адрес: `https://cliprelay.romus.pro:8443/v1`.
Проверенная версия клиента — Codex CLI 0.166.0. На сервер Codex не установлен:
клиент запускается на Mac, а HTTPS API обслуживает CliRelay.

1. Через прежнюю SSH-панель CliRelay открой ключ **Codex — ноутбук**. Его
   отдельный профиль разрешает только выбранный новый Antigravity-аккаунт и
   `gemini-3.8-flash-tiered`: 10 запросов/минуту, 300 начатых запросов/сутки UTC,
   не больше двух одновременно. В чате, терминальных аргументах и TOML ключ
   не размещай. После копирования очисти clipboard.
2. На ноутбуке открой **Keychain Access / Связка ключей**, создай обычный
   password item в связке login: имя/service
   `CliRelay:cliprelay.romus.pro:8443`, account `codex-laptop`, password — этот
   API-ключ. Ввод и подтверждение выполняет владелец ноутбука.
3. В существующий `~/.codex/config.toml` аккуратно перенеси значения из
   `codex-macos.toml.example`. Не заменяй весь файл и не дублируй уже имеющиеся
   root-параметры. Сохрани остальные provider tables и OpenAI-авторизацию.
   Пример выбирает CliRelay провайдером по умолчанию для новых чатов.
4. Полностью перезапусти Codex, создай новый чат и выбери Gemini 3.8 Flash,
   medium. При первом запросе разреши доступ к созданному item в системном
   диалоге Keychain. Для обращений к модели SSH и VPN не нужны.
5. В отдельном тестовом каталоге попроси прочитать файл, выполнить безопасную
   команду, изменить файл через patch и задать следующий вопрос в том же чате.
   Это оставшийся acceptance именно интерфейса ноутбука; текущие серверные и
   CLI-проверки его не подменяют.

В первой версии доступны текст и локальные инструменты. Hosted web search,
изображения, WebSocket и другие API-модели не опубликованы. Лимит — начатые
модельные запросы, поэтому один диалог с несколькими tool rounds может занять
несколько запросов. Ошибка upstream после допуска также считается. Квота
Google-аккаунта остаётся общей с другими его потребителями.

Отзыв доступа: в закрытой панели выключи у этого ключа **External access**.
Отказ для следующих запросов действует сразу. Если меняешь само значение
ключа, обнови item Keychain и перезапусти клиент; лимиты привязаны к ID ключа
и не сбрасываются. Чтобы вернуть прежний провайдер по умолчанию, восстанови
только ранее выбранные root model/provider settings.

Командная авторизация и удалённый каталог — штатные механизмы Codex:
[официальная инструкция по gateway](https://learn.chatgpt.com/docs/enterprise/roll-out-a-gateway).
